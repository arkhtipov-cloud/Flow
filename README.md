# Flow

Flow — дневник тренировок для iPhone с аналитикой результатов.

Приложение помогает записывать упражнения и подходы, просматривать историю тренировок и отслеживать изменения результатов.

## Возможности

- Запись веса, повторений, времени и дистанции — в зависимости от упражнения.
- Встроенный каталог с иллюстрациями, категориями и поиском по названиям и синонимам.
- Создание собственных упражнений.
- Изменение порядка упражнений в тренировке.
- История тренировок, заметки, шаблоны и сплиты.
- Графики прогресса и личные рекорды.
- Распределение прямых рабочих подходов по мышечным группам с отдельным учётом косвенного участия.
- Персональные наблюдения и рекомендации на основе записанных результатов.
- Светлая, тёмная и системная темы.

## Технологии

- Swift и SwiftUI.
- Swift Charts для графиков.
- ObservableObject и общее хранилище WorkoutStore.
- Локальное сохранение в JSON через Codable.
- Git для контроля версий.

## Запуск проекта

1. Скачайте или клонируйте репозиторий.
2. Выберите ветку `development` — в ней находится актуальная версия.
3. Откройте `Zal.xcodeproj` в Xcode.
4. Выберите схему `Zal` и симулятор iPhone.
5. Запустите приложение через Run.

Минимальная версия системы — iOS 17.

Для запуска на физическом iPhone потребуется настроить Signing & Capabilities под свою команду разработчика.

Отображаемое название приложения — Flow. Техническое имя проекта и target — Zal.

## Хранение данных

Тренировки и настройки сохраняются локально. Регистрация не требуется.

Облачная синхронизация и автоматический перенос тренировок между устройствами не реализованы. Личные тренировочные данные не входят в репозиторий.

## Особенности аналитики

Анализ использует только записанные результаты. Для определения устойчивой динамики требуется несколько сопоставимых выполнений упражнения.

Оценка силы является расчётным показателем, а не измеренным максимальным весом.

Автоматическое определение разминочных подходов использует консервативную эвристику и может ошибаться. Распределение подходов не является измерением физиологической нагрузки.
