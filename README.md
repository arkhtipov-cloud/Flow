# Flow

Flow — приложение для iPhone для ведения тренировок и просмотра результатов. Интерфейс построен на SwiftUI.

Основные возможности:

- Запись упражнений и подходов: вес, повторения, время и дистанция в зависимости от упражнения.
- Каталог с поиском и пользовательские упражнения.
- История тренировок, заметки, шаблоны и сплиты.
- Графики прогресса, личные рекорды, распределение рабочих подходов и персональные наблюдения.
- Светлая, тёмная и системная темы.

Данные сохраняются локально. Автоматическое исключение разминки из аналитики использует консервативную эвристику и может ошибаться.

Для сборки откройте `Zal.xcodeproj` в Xcode и выберите схему `Zal` (iOS 17+). Техническое имя target сохранено для совместимости; отображаемое название приложения — Flow.
